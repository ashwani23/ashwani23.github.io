Selected projects from my time at Xebia, Trantor and Net Solutions. For the roles I held on them, see [Experience](/experience/).

## Enterprise web and guest experience platform

_For Holland America Line (Carnival Corporation). Xebia._

- **Front-end and technical leadership:** Primary point of contact and lead for a 10-member front-end engineering team, bridging technical execution with product management, business analysis and QA streams to keep delivery fast.
- **Component architecture and design system:** Architect and maintain a scalable library of over 250 enterprise React components built with Next.js and TypeScript. The library is documented in Storybook and covered by unit tests to keep the UI consistent and accessible.
- **Full-stack and CMS integration:** Lead front-end integration with enterprise backends and content management systems, including Adobe Experience Manager (AEM) and REST APIs. Work on rendering performance and client-side state handling across guest-facing web properties.
- **Agile governance and delivery:** Steer agile ceremonies, sprint planning and architectural estimation. Set code review standards, CI/CD best practices and technical roadmaps for a predictable release cadence.

**Stack:** Next.js, React, TypeScript, Storybook, Jest / React Testing Library, REST APIs, AEM

## Online video conferencing and presentation platform

_Digicast. Net Solutions._

- Built an event stream generation, editing, publishing and serving tool with Next.js and Angular.
- Used AWS MediaLive, MediaStore, S3 and Pexip.
- Synced event video and slides to each viewer's buffering and connection speed ("stream stamping").
- Supported joining events from Skype for Business, mobile devices and intercom systems.

**Stack:** Next.js, Angular, AWS MediaLive, MediaStore, S3, Pexip
